# External Ambxst extensions

These projects are third-party dependencies and are not vendored in dotfiles.

## Audio Routing

Repository:
https://github.com/drpezzer/ambxst-audio-routing

Tested commit:
ef0485b303c2a01f496ea303e1a02fbf9493a04c

Local clone:
~/.local/src/ambxst-audio-routing

Install:
git clone https://github.com/drpezzer/ambxst-audio-routing.git ~/.local/src/ambxst-audio-routing
git -C ~/.local/src/ambxst-audio-routing checkout ef0485b303c2a01f496ea303e1a02fbf9493a04c
cd ~/.local/src/ambxst-audio-routing && ./install.sh
