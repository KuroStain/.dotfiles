# Atajos de teclado

Documentacion de los atajos de teclado activos definidos en este repositorio.

## Ghostty

Fuente: `.config/ghostty/config`

| Atajo | Accion | Descripcion |
| --- | --- | --- |
| `Ctrl+Shift+Flecha arriba` | `new_split:up` | Crear un split hacia arriba. |
| `Ctrl+Shift+Flecha abajo` | `new_split:down` | Crear un split hacia abajo. |
| `Ctrl+Shift+Flecha izquierda` | `new_split:left` | Crear un split hacia la izquierda. |
| `Ctrl+Shift+Flecha derecha` | `new_split:right` | Crear un split hacia la derecha. |
| `Ctrl+Alt+Flecha arriba` | `goto_split:up` | Mover el foco al split superior. |
| `Ctrl+Alt+Flecha abajo` | `goto_split:down` | Mover el foco al split inferior. |
| `Ctrl+Alt+Flecha izquierda` | `goto_split:left` | Mover el foco al split de la izquierda. |
| `Ctrl+Alt+Flecha derecha` | `goto_split:right` | Mover el foco al split de la derecha. |
| `Ctrl+Alt+[` | `goto_split:previous` | Mover el foco al split anterior. |
| `Ctrl+Alt+]` | `goto_split:next` | Mover el foco al split siguiente. |
| `Ctrl+Shift+W` | `close_surface` | Cerrar la superficie actual. |

## Yazi

Fuente: `yazi/.config/yazi/keymap.toml`

| Atajo | Accion | Descripcion |
| --- | --- | --- |
| `Shift+Enter` | `open --interactive` | Abrir el menu "Abrir con..." para elegir una aplicacion. |

## Notas

- `nano/.nanorc` contiene ejemplos de atajos, pero estan comentados, asi que no se consideran activos.
- `bash/.bashrc` contiene aliases y funciones de shell, pero no define atajos de teclado activos.
- `README.md` menciona `keymap.toml`, pero no define atajos directamente.
